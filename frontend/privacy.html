Privacy Policy & Anonymity Protocol

Strict protocols protecting student privacy, anonymity, and data minimization.

1. Zero Student Identity Collection on Grievances

When you submit an accessibility grievance, the system does not ask for or store your name, student registration number, department enrollment, or contact information. The generated Secret Code (e.g. SAK-2026-8891) is a standalone token.

2. Admin Visibility Safeguards

Administrative staff, nodal officers, and auditors view secret codes exclusively. Backend APIs never transmit or log student identity fields to admin endpoints, preventing inadvertent bias or retaliation.

3. Local Accessibility Preference Storage

Accessibility settings (such as Dyslexia mode, high contrast, and font size choices) are stored strictly within your local browser storage and are never uploaded or linked to a profile.

4. Speech Audio Privacy

Spoken voice commands processed by the Web Speech API are handled through native browser interfaces. Audio input is never recorded, saved, or uploaded to external third-party servers by SakshamSetu.
