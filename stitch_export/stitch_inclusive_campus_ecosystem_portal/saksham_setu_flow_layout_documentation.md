# Saksham Setu - Comprehensive Layout Flow

This document maps the complete user journey for Saksham Setu, ensuring all specialized portals and administrative tools are cohesive and accessibility-first.

## 1. Entry & Authentication
- **Login & Role Selection** ({{DATA:SCREEN:SCREEN_13}}): High-contrast landing page where users choose between 'Student' or 'Administration'. 
- **Disability Mode Selection**: For students, a secondary choice to set the interface to Voice-First (Visual/Dyslexic), Hearing Impaired, or Physically Challenged.

## 2. Specialized Student Portals (Refined Structure)
- **Voice-First Portal** ({{DATA:SCREEN:SCREEN_2}}): Optimized for visually challenged/dyslexic students. Primary interaction via voice commands for ambulance calls and service lookups.
- **Hearing Impaired Portal** ({{DATA:SCREEN:SCREEN_4}}): Visual-first interface with large touch targets, visual-only emergency triggers, and text-based service directories.
- **Physically Challenged Portal** ({{DATA:SCREEN:SCREEN_3}}): Prioritizes motor accessibility with simplified navigation, large action buttons for transport, and the high-contrast campus map ({{DATA:IMAGE:IMAGE_9}}).
- **General Campus Overview** ({{DATA:SCREEN:SCREEN_8}}): A text/visual hybrid for general readability.

## 3. Administrative Tools (Modernized Structure)
- **Admin Compliance Dashboard** ({{DATA:SCREEN:SCREEN_5}}): Centralized tracking for government law checklists, compliance scoring, and automated recommendations.
- **Grievance Tracker (Admin View)**: Anonymous oversight using secret codes to track student issues from 'Registered' to 'Completed'.

## 4. Shared Services & Specialized Features
- **Grievance Status Tracking** ({{DATA:SCREEN:SCREEN_6}}): A login-free portal where students can enter their unique code to see live progress updates.
- **Emergency Help / Ambulance Pooling**: Accessible via voice or tap depending on the portal mode.
- **AI Tutor & Transport Pool** ({{DATA:SCREEN:SCREEN_14}}): 'Coming Soon' placeholder pages for Phase 2 implementation.

## 5. Design Constraints & Standards
- **Background**: Pure white (#FFFFFF).
- **Visuals**: Zero drop shadows, high-contrast borders, no gradients, no Lucide/sparkle icons.
- **Typography**: Clear hierarchy using Atkinson Hyperlegible Next for maximum readability.
